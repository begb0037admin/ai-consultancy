## How to log a new entry

Add a row (or dated sub-section) with:
- **Claim** — the exact thing you want to be able to say
- **Detail** — what actually happened / what's true, including any limits on how it can be phrased
- **Source** — where this came from (call, email, contract, live demo URL, etc.)
- **Logged** — the date it was added here

If a claim can't be written this way, it isn't evidence yet.
