# Launch Plan

This checklist is the live view of launch progress. Tick items as they are completed and capture the supporting decision or learning in [NOTES.md](NOTES.md).

Phase 4 starts alongside Phases 2 and 3. Do not wait for finished demos or a polished website before beginning discovery conversations.

## Phase 1 — Lock the offer

- [ ] Write and refine the one-line positioning statement in [README.md](README.md)
- [ ] Define who this is for and who it is not for

## Phase 2 — Build proof with synthetic-data demos

- [ ] Rebuild the knowledge-base search demo with synthetic company data
- [ ] Build the support-triage dashboard demo with synthetic data
- [ ] Confirm that neither demo contains real former-employer data, branding, system names, or screenshots

## Phase 3 — Create a minimal web presence

- [ ] Build a one-page site with the positioning line, both demos, and a contact or booking route
- [ ] Deploy the site with GitHub Pages

## Phase 4 — Start first outreach in parallel

- [ ] Draft an outreach message framed around discovery, not a hard pitch
- [ ] List the first 10–20 contacts from the founder's network
- [ ] Run 3–5 discovery calls and log the learnings in [NOTES.md](NOTES.md)

## Phase 5 — Define pricing and packaging

- [ ] After Phase 4 conversations, define offer tiers and pricing based on what real prospects value and can afford
